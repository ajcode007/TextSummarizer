# TextSummarizer using Huggingface

### Workflow

1. config.yaml -> basic configuration we needs to update
2. Params.yaml -> update the model parameters(Hyperparameter)
3. config entity
4. Configuration manager
5. update the componet - Data Ingestion, Data Transformation, Model Trainer
6. Create our Pipeline -> Traning Pipeline, Prediction Pipeline
7. Front End -> APi's, Training API's, Batch Prediction API's
